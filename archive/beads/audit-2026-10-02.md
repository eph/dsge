## Runtime probe reproduction

The dated [probe script](audit-2026-10-02.py) contains the minimal AR(1), C++ export,
owner-expectations, DGS file-path, extreme-horizon, and generic-prehistory checks,
as well as IRFOC API inspection. It records unresolved behavior as data rather
than asserting that bugs should exist forever. Results are retained separately
for [master](audit-master.json) and [security](audit-security.json).

From the migration repository, export the exact code snapshots and run each probe
using an environment containing the project's dependencies. For example:

```sh
audit_dir=$(mktemp -d)
mkdir "$audit_dir/master" "$audit_dir/security"
git archive 0cfeca45eafdaefb420fb78ddba5fb1c6f319fe9 | tar -x -C "$audit_dir/master"
git archive 5eff5e011f59cee81b278d053702254d4d8ec03b | tar -x -C "$audit_dir/security"
uv run python archive/beads/audit-2026-10-02.py "$audit_dir/master" "$audit_dir/master.json"
uv run python archive/beads/audit-2026-10-02.py "$audit_dir/security" "$audit_dir/security.json"
```

The probe explicitly selects the supplied checkout before importing `dsge`. The
FHP comparison computes the allocation from the independently constructed 2×2
triangular recurrence, without using the reduced-state reconstruction under test.
Numeric evidence is environment-specific; the code/API inspection is anchored to
the exact commits above.
