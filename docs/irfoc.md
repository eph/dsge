# IRFOC

`dsge.irfoc.IRFOC` solves finite-horizon counterfactual paths for a linear model by choosing an instrument-shock sequence that enforces a policy rule along a baseline path.

Typical workflow:

```python
from dsge import read_yaml
from dsge.irfoc import IRFOC

m = read_yaml("dsge/examples/irfoc/nk_irfoc_demo.yaml")
p0 = m.p0()
lin = m.compile_model()

baseline = lin.impulse_response(p0, h=40)["er"].loc[:, ["pi", "y", "i", "re", "u", "deli"]]
irfoc = IRFOC(m, baseline=baseline, instrument_shocks="em", p0=p0, compiled_model=lin)

cf = irfoc.simulate("i = 1.5*pi + 0.5*y")
```

## Affine rules

Use `simulate(...)` for affine rules in current and lagged variables:

- `i = 1.5*pi + 0.5*y`
- `i = 0.85*i(-1) + 0.15*(1.5*pi + 0.5*y)`

If you need the implied instrument-shock path, pass `return_details=True` and inspect the returned `IRFOCResult`.

## Dynamics And Limits

IRFOC solves for a **finite-horizon, fully anticipated** instrument-shock sequence. That is the right object for
pre-announced counterfactual wedges and for finite-horizon commitment-style exercises, but it is not the same as
recompiling the model with different structural parameters and simulating that new state-space system.

In small policy-rule comparisons, those two objects can coincide exactly. In larger models with persistent dynamics,
the direct changed-parameter path may not lie exactly in the finite-horizon span generated by the chosen instrument
shock under the baseline model. In that case IRFOC can enforce the requested rule very accurately while still only
matching the recompiled-model path approximately.

If you are validating a full parameter-change counterfactual, treat the direct state-space simulation of the
recompiled model as the ground truth and use IRFOC as a finite-horizon approximation/cross-check rather than an
identity by default.

## Piecewise rules

Rules containing `max()` or `min()` use the MILP backend via `simulate_piecewise(...)`:

```python
cf = irfoc.simulate_piecewise(
    "i = max(-0.2, 1.5*pi + 0.5*y)",
    u_bounds=(-5.0, 5.0),
)
```

`u_bounds` should be wide enough to contain the implied instrument-shock sequence. The example script below computes robust bounds from unconstrained runs first.
